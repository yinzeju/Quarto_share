# 周报模板：从快照到精确 DMD 预测

本例仿照作者 20261029 周报的讲解方式和视觉组织：从实际模型开始，逐页构造数据矩阵、回归、SVD、谱与预测，说明每个对象怎样得到、下一步用在哪里。13 页 slides 保留必要计算步骤，[详细汇报说明](汇报说明.qmd)展开完整推导、假设、来源、图表和逐页安排。

内容选用 Tu et al. (2014) 的精确 DMD。双自由度阻尼振子的数据、GIF 和图均由本项目脚本实际生成，明确属于**教学合成算例**，不包含作者原周报的研究实验结果。数据与图片已附带，可直接渲染，无需先运行计算。

## 直接预览和构建

在本目录运行：

~~~powershell
quarto preview slides.qmd
quarto render --no-execute
~~~

两份 HTML 生成在 _output/slides.html 与 _output/汇报说明.html。第 6 页是整张投影片滚动的完整推导，可用鼠标滚轮、方向键或 PageUp / PageDown 阅读。

## 让 AI 具体学什么

| 示例位置 | 可复用的表达方式 |
|---|---|
| 第 1–2 页 | 先定义物理对象、已知/未知量，再用相邻样本构造矩阵 |
| 第 3–5 页 | 每页有可继续使用的中间结果，给出定义、维度与计算顺序 |
| 第 6 页 | 对非平凡步骤逐次代入，保持正常字号和完整数学链 |
| 第 7–9 页 | 算法步骤对应公式，训练/预测信息分开，指标直接来自计算 |
| 第 10 页 | GIF 与静态图并排，动画交代运动，图表承担定量解释 |
| 第 11 页 | 两幅图片并排，分别回答不同的科学问题 |
| 第 12 页 | 上方双图比较分量，下方横图展示联合关系，保留坐标 |
| 第 13 页 | 计划对应实际缺口，不把尚未运行的检验写成结果 |

投影文字只保留理解对象、公式、理由和结果需要的信息。完整解释放在说明中；不要用口号、导航、设问或复述公式的段落填满页面。

## 替换为自己的汇报

## 计算与来源

重新生成数据和图片：

~~~powershell
python scripts/generate-demo.py
~~~

依赖 NumPy、SciPy、Matplotlib 和 Pillow；仅重新渲染 HTML 时无需这些数值库。生成器保存未舍入数据、误差定义、系统矩阵和数值断言，图表与 GIF 使用同一条状态轨迹：

- [trajectory.csv](data/trajectory.csv)：无量纲状态与训练/预测划分。
- [results.json](data/results.json)：指标、参数和数值一致性检查。
- [source-manifest.json](sources/source-manifest.json)：方法来源、版式来源与图片哈希。
- [references.bib](references.bib)：已核对的真实文献记录。
- [layout-validation.json](sources/layout-validation.json)：13 个逻辑页、43 处公式、GIF 播放与布局检查的实际记录；截图和浏览器临时文件不进入分享包。

方法文献：[Tu et al. (2014), Journal of Computational Dynamics](https://doi.org/10.3934/jcd.2014.1.391)。本例只验证已注明条件下的教学计算，不代表新方法、真实实验泛化或真实物理参数辨识。
