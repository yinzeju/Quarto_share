# 中文科研汇报幻灯片

配合 `presentations` 技能创建或编辑 PPTX。以源材料为唯一内容依据，使用统一浅色科研视觉，并把所有数学公式保留为可编辑 LaTeX 源代码。

## 开始前

- 新建、彻底重做或统一视觉时，先阅读 [references/style-guide.md](references/style-guide.md)。
- 涉及英文材料、图表标签或技术术语时，阅读 [references/chinese-terminology.md](references/chinese-terminology.md)。
- 交付前必须逐项执行 [references/qa-checklist.md](references/qa-checklist.md)。
- 同时遵守当前项目的 `AGENTS.md`。若用户另有明确要求，以用户要求为准。

## 工作流程

### 1. 锁定内容来源

- 完整读取用户指定的 Markdown、论文、数据文件和已有 PPT。
- 提取标题层级、核心结论、公式、数据、图片链接和页间顺序。
- 不添加材料中没有的实验结果、事实判断、研究动机或技术路线。
- 默认把 Markdown 每个一级大标题映射为一页，除非源文档或用户另有约定。

### 2. 建立逐页内容表

- 每页只保留一个中心结论。
- 为每页记录：页标题、结论句、必要证据、公式、图表类型、图片占位和讲述衔接。
- 先决定信息结构，再决定版式。不要用装饰填补内容不足。
- 若该页已有图片链接，将图像区域留空并保留合理占位，不生成替代图。

### 3. 统一中文表达

- 标题、正文、图注、坐标、图例、表头和页脚使用中文。
- 将通用英文概念翻译为中文；仅保留人名、算法名、模型名、标准缩写和必要专有词。
- 首次出现的必要专有词优先写成“中文名称（专有词或缩写）”，后续保持同一写法。
- 不使用英文短语充当版面装饰。

### 4. 选择证据表达

- 优先顺序为：数学公式、数据表格、定量曲线、坐标系或相图、矩阵或算子结构、神经网络、几何体、动力学或控制流程。
- 每个视觉元素必须对应材料中的具体含义，并具有清晰标签、图例、变量或方向。
- 只有源材料确实需要且没有现成图片链接时，才创建技术图示。
- 禁止生成无关概念图、夸张场景、霓虹装饰、拟物插画或没有定量含义的科技背景。

### 5. 固定视觉系统

- 全篇使用白色或极浅中性色背景，保持背景一致。
- 使用克制的深蓝、科技蓝和青绿色作为主要强调色，警示或对比色少量使用。
- 通过细线、坐标刻度、浅网格、结构化数学图形和紧凑排版体现科技感。
- 固定标题位置、内容边距、字号层级、页码和页脚，不在不同页面随意变化。
- 避免大量圆角卡片；优先使用清楚的分区、细分隔线和对齐关系。

### 6. 写入公式

- 将公式作为普通、可编辑文本框写入，内容保持原始 LaTeX 源代码。
- 不调用公式渲染器，不生成公式图片、SVG 或路径轮廓。
- 使用等宽字体，确保 `\`、`_`、`^`、花括号和环境命令可见且可复制。
- 公式过长时分行或调整布局，不得以牺牲可读性为代价缩小字号。

### 7. 构建与编辑

- 使用可编辑文本、形状、表格、图表和连接线构建页面。
- 编辑已有 PPT 时保留已确认的主题、色板、标题位置和页间节奏，并在正确位置插入新页。
- 连接线必须在图形之后创建，并准确吸附到节点边缘；不得穿过标签或无关节点。
- 不用密集小字承载论证。必要时删减次要信息或拆页，但不得擅自改变用户指定的页结构。

### 8. 渲染与校验

- 生成 PPTX 后渲染所有页面，并运行布局和溢出检查。
- 先看整套缩略图，检查背景、标题、留白、视觉密度和色彩是否一致。
- 再看新增页、公式密集页、表格页和复杂流程页的全尺寸渲染。
- 修复所有遮挡、越界、乱码、错别字、错误连线、低对比度和不可读字号后重新渲染。
- 只有通过 [references/qa-checklist.md](references/qa-checklist.md) 后才交付。

## 不可妥协项

- 不脱离源材料自作主张。
- 不生成无关或夸张的概念图。
- 不出现黑白页面交替或无理由的深浅主题切换。
- 不把公式渲染成图片；只保留 LaTeX 源代码文本。
- 不用英文承担可翻译的正文信息。
- 不交付未经逐页渲染检查的 PPTX。
