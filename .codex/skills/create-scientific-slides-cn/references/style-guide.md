# 中文科研汇报视觉规范

## 基础画布

- 默认使用 16:9 宽屏画布。
- 四周保留稳定安全边距；标题、正文、页码和图注不得贴边。
- 全篇使用白色或极浅灰蓝背景。除非用户明确要求，不使用纯黑背景和大面积深色底。
- 背景可以包含极淡的坐标网格、细线或局部几何纹理，但不得干扰阅读。

## 推荐色板

| 用途 | 颜色 | 十六进制 |
|---|---|---|
| 主标题与正文深色 | 深海军蓝 | `#17324D` |
| 主要强调 | 科技蓝 | `#2F6B9A` |
| 次要强调 | 青绿色 | `#168A8A` |
| 风险或负向对比 | 克制红 | `#B64B4B` |
| 次级提示 | 暖金色 | `#A87316` |
| 辅助线与边框 | 冷灰 | `#B8C4CE` |
| 页面背景 | 极浅灰蓝 | `#F7F9FB` |

- 同一语义始终使用同一颜色。
- 每页主要强调色不超过两种，红色只用于必要的风险、误差或反例。
- 禁止霓虹渐变、彩虹配色、强发光和高饱和大色块。

## 字体层级

- 中文优先使用“微软雅黑”或系统中清晰稳定的无衬线中文字体。
- LaTeX 源代码使用 `Consolas` 等等宽字体。
- 标题建议 28 至 34 磅，正文建议 17 至 22 磅，图注和页脚不得低于 11 磅。
- 同一层级字号必须统一。不要依靠连续缩小字体解决内容过多。
- 标题简短、结论先行；正文使用短句和结构化表达。

## 页面骨架

- 标题固定在页面上方同一位置，并用细线或小型色块形成稳定识别。
- 主体优先采用以下结构：左文右图、上结论下证据、中心公式加两侧解释、全宽表格或全宽曲线。
- 每页只突出一个中心结论；其他元素用于证明、解释或限定该结论。
- 保持适度留白，不用装饰卡片填满页面。
- 避免机械的三栏卡片式布局；需要分组时使用对齐、细分隔线和层级标题。

## 数学公式

- 公式必须作为原始 LaTeX 字符串写入文本框，例如：

```latex
\mathbf{z}_{t+1}=\mathbf{K}\mathbf{z}_t+\mathbf{B}\mathbf{u}_t
```

- 公式框使用浅色底或细边框即可，不使用高光、浮雕或公式截图。
- 变量定义紧邻公式放置，避免把符号解释散落到远处。
- 多行公式保持左对齐或按等号对齐，并留出足够行距。

## 数据表格

- 表格优先展示可比较的指标、方法、数据集、误差和结论。
- 表头使用浅蓝灰底，正文使用白底和极浅隔行色；避免全框粗线。
- 小数位、单位和正负号统一，对齐数值列。
- 只突出最关键的最优值、变化量或异常值，不把整张表涂满颜色。
- 没有真实数据时不得制造示例数值冒充实验结果。

## 曲线与坐标系

- 坐标轴、单位、图例和变量必须完整，刻度密度适中。
- 用线型、颜色和标记共同区分曲线，保证黑白打印时仍可辨认。
- 关键点可以用虚线投影、局部标注或误差带解释。
- 不使用无坐标、无单位、无来源的装饰性波形。

## 网络与流程

- 神经网络用节点、层、张量尺寸和有向连接表示，不用大脑、机器人等隐喻图。
- 动力学与控制流程应明确状态、控制、观测、模型、损失和反馈方向。
- 箭头只表示真实的数据流、控制流、时序或因果关系。
- 连接线在节点之后创建，端点贴合边缘，避免穿过文本和其他节点。
- 循环与反馈路径应使用不同于主流程的线型或颜色，并给出标签。

## 几何与算子图示

- 几何体、流形、向量场、特征空间和谱结构必须有坐标、变量或数学含义。
- 可使用投影、子空间、基向量、轨迹、等值线和特征值分布表达技术关系。
- 三维透视只在确实需要表达空间关系时使用，避免夸张透视和装饰性悬浮物。

## 科技感边界

允许：浅网格、坐标刻度、细线扫描结构、矩阵、算子符号、曲线、拓扑、微弱蓝青强调。

禁止：太空背景、粒子爆炸、发光芯片、机器人、人脑隐喻、炫彩隧道、无含义的全息界面、电影海报式构图。

## 图片策略

- 优先使用源材料提供的实验图、装置图、论文图和数据图。
- 若源页已有图片链接，图片区域保持为空，等待用户后续插入。
- 仅在源材料明确需要且没有现成图片时创建技术图示。
- 技术图示应采用矢量形状和可编辑标签；不可用无关概念插画替代科学信息。
