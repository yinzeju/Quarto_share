# 中文科研汇报交付检查表

交付前逐项核对。任一硬性项不通过，都需要修改并重新渲染。

## 内容忠实度

- [ ] 页数、页序和标题层级符合源材料或用户明确要求。
- [ ] 每页中心结论均可在源材料中找到依据。
- [ ] 没有虚构数据、实验、引用、公式、结论或技术路线。
- [ ] 压缩和改写没有改变原意。
- [ ] 源材料已有图片链接的页面保留了空白图片区域，没有生成替代图。

## 中文表达

- [ ] 标题、正文、图注、坐标、图例、表头和页脚使用中文。
- [ ] 可翻译的通用英文术语已使用准确中文。
- [ ] 人名、模型名、装置名和标准缩写的保留确有必要。
- [ ] 首次出现的缩写有中文全称或简要解释。
- [ ] 同一概念、符号和缩写在全篇写法一致。
- [ ] 没有英文装饰标题或无意义的英文大写词。

## 数学与数据

- [ ] 所有公式都是可编辑的 LaTeX 源代码文本。
- [ ] 没有公式截图、渲染图片、SVG 轮廓或不可编辑公式对象。
- [ ] 反斜杠、上下标、花括号和环境命令完整无误。
- [ ] 变量定义、单位、坐标轴、图例和误差说明齐全。
- [ ] 表格数字、小数位和单位统一且正确对齐。
- [ ] 没有用装饰性波形或虚构数据替代真实证据。

## 视觉一致性

- [ ] 全篇使用统一的白色或极浅中性色背景。
- [ ] 不存在黑白页面交替或无理由的主题切换。
- [ ] 标题位置、字号层级、边距、页码和页脚一致。
- [ ] 色彩克制，同一语义使用同一颜色。
- [ ] 科技感来自数学结构和细节，不来自霓虹、概念插画或夸张效果。
- [ ] 页面留白合理，没有为填满空间而添加无关元素。

## 技术图示

- [ ] 每个曲线、网络、几何体、坐标系和流程图都有明确技术含义。
- [ ] 节点、变量、方向、图例和关键关系均有标注。
- [ ] 箭头只表达真实的数据流、控制流、时序或因果关系。
- [ ] 连接线端点准确，没有穿过文字、标签或无关节点。
- [ ] 图形配色、线型和标记足以区分类别。

## 布局与渲染

- [ ] 已渲染并检查每一页，而非只检查源代码或编辑视图。
- [ ] 已检查整套缩略图中的背景、节奏、密度和风格一致性。
- [ ] 已全尺寸检查新增页、公式页、表格页和复杂流程页。
- [ ] 没有文字溢出、遮挡、越界、乱码、低对比度或不可读字号。
- [ ] 没有对象超出画布或被错误裁切。
- [ ] 修改后已重新渲染并复查相关页面。

## 交付文件

- [ ] PPTX 可以正常打开，页序和页码正确。
- [ ] 关键文本、公式、表格和技术图形保持可编辑。
- [ ] 临时渲染文件、调试文件和中间产物未混入最终交付目录。
- [ ] 最终答复准确说明输出路径和已完成的验证。
