# Journal Adaptation

Read the current official journal author guide and publisher LaTeX instructions before changing submission settings. Record URLs, date, verified requirements, and inaccessible or unresolved items in the individual paper. Third-party summaries are supplementary evidence, not certification of current requirements.

Check article type/language, abstract and keyword limits, front matter, author/affiliation/corresponding-author fields, reference style/backend, review/anonymity mode, figures/tables, separate highlights or graphical abstract, supplementary material, and required declarations. Preserve missing real-author information as unresolved rather than inventing approvals or statements.

Prefer an appropriate maintained Quarto journal extension when available, recording/vendoring its exact revision and notices. Treat it as a starting point: compare its class, bibliography backend/style, metadata, resources, and engine assumptions with the actual journal requirements. Keep journal-specific configuration in the paper, using profiles when helpful.

Verify anonymity across the complete requested package when blind review is required. Confirm permitted dependencies and source layout for the submission platform. Read `latex-handoff.md` for portable source packaging and local independent compilation. Report server compatibility or guideline access gaps explicitly; a locally rendered PDF alone does not certify submission readiness.
