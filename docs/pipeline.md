# Quarto 科研出版操作管线

此文档整理现有项目规则中的操作步骤，并非自动执行脚本。所有命令均在使用者自己的具体 Quarto 项目中运行。

## 1. 定位项目与目标

找到 `_quarto.yml` 和入口文档；分类目录不一定是项目根目录。读取项目及父目录的规则，检查配置、文献库、引用样式、模板、素材与已有输出。确认出版类型和目标格式。

使用 `quarto-publication`。涉及具体语法时读取技能的 `references/publication-patterns.md`；涉及版本差异时按 `references/official-source-index.md` 核对官方文档。

## 2. 阅读材料并建立结构

完整读取自己的材料，提取论点、公式、数据、引用、素材和论证关系。先确定章节或展示单元的中心结论，再安排证据与衔接。区分理论结论、实验观察、解释性推断和待验证假设。

缺失内容明确标注，不虚构事实、实验结果、引用或技术路线。编辑已有项目时延续现有结构、含义和风格。

## 3. 统一术语、符号与引用

默认使用准确克制的中文科研表达，必要专有名词首次给出解释。符号遵守使用者自己的项目约定。

引用使用 `.bib` 中的真实键。图、表、公式、章节、代码清单分别使用 `fig-`、`tbl-`、`eq-`、`sec-`、`lst-` 前缀；标识避免下划线。

科研幻灯片的文献引用统一放在对应页左下角，显示为 `作者(年份)`；多篇按内容出现顺序用分号分隔，同页去重。为引用预留空间，核验作者和发表年份，完整书目附录不替代逐页引用。

## 4. 编写源文件

使用语义化 Markdown、原生 LaTeX、相对素材路径和 Quarto 交叉引用组织 `.qmd`。共用设置进入 `_quarto.yml`，文档专属元数据进入文档 YAML。数学源代码保持可编辑，并由目标格式正常渲染。

图表追溯到材料、数据或代码，相关素材在具体项目内维护。

科研幻灯片默认使用 16:9、白色或极浅灰蓝背景、深海军蓝正文及蓝青强调。先建立逐页结论与证据表，再安排统一标题、字号层级、留白和左下角引用区。公式正常渲染；详细视觉与引用规则见 [科研汇报规范](../guidelines/research-reports/AGENTS.md)。

## 5. 预览与最小范围验证

检查环境并迭代预览：

```bash
quarto check
quarto preview
```

针对修改的文档渲染，文件名需换成项目实际文件：

```bash
quarto render index.qmd
```

按项目需要选择目标格式，例如：

```bash
quarto render --to html
quarto render --to pdf
quarto render --to docx
```

只验证项目需要的格式；PDF、代码执行和特定模板可能需要额外依赖。列出命令不代表验证已经完成。

## 6. 完整构建与验收

修改全局配置、模板、样式或参考文献后应完整渲染；书籍最终交付前必须完整渲染：

```bash
quarto render
```

打开实际输出，检查公式、上下标、编号、引用、表格、图例、导航、分页、代码输出和资源路径。幻灯片逐页检查遮挡、越界、乱码和可读性。修复后重新渲染。

## 7. 交付

交付时记录实际命令、结果、输出位置和未解决的依赖问题。保留原有素材和输出。
