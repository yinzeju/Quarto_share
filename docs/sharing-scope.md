# 分享范围与维护边界

本次完整保留两套技能及其参考文件、界面元数据。仓库级规则移除了本机绝对路径；科研汇报规则整理为通用英文版，移除了私人符号规范路径。README、操作管线和本说明为分享新增文档。

技能自身的一般语法示例、术语表和视觉规则保留。未从具体出版项目提取正文、研究图表或实验数据。

排除所有出版项目、正文、提纲、口述稿、笔记、论文、文献库、数据、图片、视频、演示文稿、模板二进制文件、输出和缓存。同时排除个人 `.codex/config.toml`、私人符号文件、浏览器状态、认证信息、临时文件和原仓库 `.git`。

本仓库从空目标仓库独立提交，不继承原出版仓库分支或历史，不自动同步原仓库。

后续更新步骤：

1. 单独克隆分享仓库，按上述范围选择来源文件，禁止递归复制整个出版工作区。
2. 阅读待更新文件，清除私人路径、资料依赖和混入的研究内容。
3. 检查 `git status --short`、`git diff --cached --stat` 和 `git diff --cached`。
4. 核查暂存文件与提交历史符合分享范围，再提交推送。

`.gitignore` 只能辅助防误操作，不能识别所有敏感内容，也不能隐藏已提交文件。不要使用 `git push --mirror`，也不要向此仓库推送原出版仓库历史。
