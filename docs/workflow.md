# 科研出版流程与规则

## 1. 按汇报目的选择入口

| 工作 | 核心技能 | 主要成果 |
|---|---|---|
| 研究说明、科研汇报 | `quarto-report` | 正文报告，或详细汇报说明与幻灯片 |
| 周报 | `weekly-report` + `quarto-report` | 连贯的文献与工作汇报、实验展示、下一步计划、内容目录 |
| 正式论文 | quarto-paper | 研究简报、论文、期刊 PDF 和独立 LaTeX 源码包 |

直接运行的示例位于 [Paper/Template](../Paper/Template/README.md) 和 [Report/Weekly/Template](../Report/Weekly/Template/README.md)。论文例复制作者原测试项目；周报例展示详细说明、13 页连续推导和 GIF/图组布局。模板是可阅读、可渲染的制作依据，真实内容要以用户证据替换。

按汇报目的和输出选择规则，文件扩展名不能单独决定路由。`weekly-report` 专门组织周报内容，符号、引文、输出和渲染统一复用 `quarto-report`。

源材料 → 证据与符号整理 → 详细汇报说明 → 目标源稿 → 渲染与视觉检查 → 交付与授权范围内的同步。

## 2. 先找到具体项目与真实证据

在单个汇报项目内工作，先检查已有源稿、`_quarto.yml`、样式、参考文献、图表、数据、脚本和输出。工作区根目录、`Report/` 和 `Report/Weekly/` 是集合目录；包含实际项目配置或源稿的目录才是制作和渲染入口。

优先使用用户指定材料，不需要设置资料库路径。未指定文件时，从当前项目、工作区中的相关材料及项目说明检索，先找文件名，再找内容。材料提及论文时，先在可用的本地文献中核对题名、DOI 或作者年份，读取对应 Markdown，必要时对照 PDF 中的公式和原图；材料缺失后再从出版商、正式预印本或作者机构来源补足。本地库不可访问时如实说明。

重要结论应能对应到推导、实验输出、表格、原图或真实文献。笔记和内部实验报告记入来源清单；引用的真实文献记录记入 `.bib`，两者不混用。理论、观察、解释和计划要明确区分，缺失证据保留可见 TODO，不用合理猜测填成研究结果。

## 3. 统一数学与术语

报告在写公式前读取技能内附的[作者 Core 符号约定](../.agents/skills/quarto-report/references/notation-core.md)。这份文件直接复制自作者实际使用的 Core，涵盖对象字体、空间与算子、内积与伴随、谱记号、微分、扰动和索引等约定，随技能直接使用。领域内新增的符号在当前汇报中明确界定。

同一份报告内，符号的数学角色和物理含义应保持一致，覆盖详细说明、slides、公式、图表、坐标和图例。来源论文使用不同记号时，记录映射；必要复用要用作用域、下标或定义区分。定义应给出必要维度、单位、索引、假设和适用条件，不只列一个符号名称。

保留可编辑数学源。Quarto 从 `.qmd` 正常渲染 LaTeX；直接制作 PPTX 的继承约定是可编辑文本框中的字面 LaTeX 源码，适用范围和例外见 [PPTX 分支](../.agents/skills/quarto-report/references/pptx.md)。术语默认使用准确中文，保留可检索的专有名词与必要缩写，首次使用时解释。

## 4. 科研汇报：先完成详细汇报说明

制作新 slides 或实质修订前，先在项目中完成 `汇报说明.qmd` 或已有等价文档。它和原始证据、用户指令共同构成制作依据，不能由标题大纲代替。

先交代研究问题、受众、范围、主线、章节规划、材料清单和符号来源，再逐页写清：

1. 页码、标题、目的和核心结论。
2. 计划展示的文字、公式、图表与布局。
3. 定义、假设、维度、单位、完整相关推导及非平凡步骤的理由。
4. 支撑材料、数据或原图位置，以及尚缺证据。
5. 本页真实文献的完整引用信息。
6. 口头解释、理解难点和下一页的衔接。

说明可以比 slides 详细；压缩投影内容时保留说明中的完整推导。需要精讲的步骤仍应在 slides 上可跟随，不能只把过程藏进说明而直接跳到最终公式。窄范围修改同步更新受影响的说明和页面。

## 5. 周报：组织连续推导与近期工作

可按“核心文献精讲 → 相关方法概讲 → 创新与局限 → 近期工作 → 实验 → 下一步计划”组织，但应按材料和时长调整。

精讲以“起点 → 推导或处理 → 可用结果”构成一页的逻辑阶段，下一页从已有结果继续。每个新矩阵、变量或计算对象都要交代来源与用途；近似和假设在生效处出现。概讲围绕“研究问题 → 核心思想 → 工具 → 流程 → 输出”，只保留所选深度需要的数学。

长推导可采用整页垂直滚动，并保留正常字号；PDF 导出必须检查全部内容，不能只有初始屏幕。文献总结比较创新、假设、局限及与当前工作的关系，不把实验规模小直接推断成理论上无法扩展。

近期工作说明已有模型和数据、待解决部分、拟采用的表达或计算、学习目标和最终可用模型。区分训练阶段可得信息与预测时可得输入。下一步计划对应实际缺口、拟做动作和应验证的问题。

新周报默认放在 `Report/Weekly/YYYYMMDD/`，日期按用户指定报告日或用户本地日期；修订复用原项目，同日新报告保留旧内容并采用清晰的独立项目名。完成后更新 `Report/Weekly/README.md` 的主题、简要内容和相对项目链接。

## 6. 投影页面与实验展示

默认中文、浅色背景、16:9、稳定页边距与标题/页脚位置。使用克制的蓝色、青色与灰色；优先展示有科学含义的公式、矩阵、流程、定量曲线、表格和原图。字号应适合投影，拥挤时拆页或调整内容。

标题给出明确科学信息；删除重复公式含义的句子、设问、装饰标签和制作导航。每句可见文字都应帮助理解对象、公式、推理或结果。图表给齐坐标、单位、图例、精度和必要定义，不能用装饰图替代实验依据。

每张使用文献的内容页在左下角保留引用区：作者、年份、期刊或真实载体、论文题目，每条独占一行。多条纵向排列，内容不遮挡引用。个人笔记、内部实验报告和本机路径不进入该引用区。

实验按“对象 → 比较与评价条件 → 图与数值 → 支持的结论”展示。优先采用表格、实验图片和响应曲线，补充解释它们所需的数据划分、预测时长、指标定义、单位与比较条件。平均指标要明确包含哪些量、权重和评价集；派生统计先用未舍入数据计算再显示。观众可见名称应清晰，原始任务名与证据映射留在说明中。

## 7. 论文：从研究简报到独立源稿

用 quarto-paper 在具体 Paper 项目内记录研究问题、文献支撑的缺口、可支持的贡献、已有证据和待补信息。先写有证据的正文，再对齐引言、摘要、贡献和结论。模型、推导、原图、数值表格和复现脚本都要能追溯到来源。

期刊配置与科学内容分开；模板内已附带 Elsevier 扩展、profile、原许可及历史要求记录。复制模板不能替代当前官方作者指南核验。真实作者、机构、基金和声明由真实信息替换；没有信息时保留 TODO，不能沿用虚构测试身份。

论文模板实际展示制造解、弱式、有限元离散、误差度量、图表与引用。导出期刊 PDF 后，打包实际生成的 LaTeX 和必要本地依赖，再在新解压目录独立编译。验证的是技术路径和已注明条件的算例，不是新颖性、全面期刊合规或投稿授权。

## 8. 渲染、检查与交付

从具体项目运行预览和交付构建，按实际文件名与格式调整：

```powershell
quarto preview
quarto render
```

共享配置、模板、样式或文献发生变化后，重新构建受影响的汇报项目。普通排版核验复用已核实结果，研究执行按用户任务处理，不能把重新计算当作每次渲染的默认动作。[Quarto 项目与渲染说明](https://quarto.org/docs/projects/quarto-projects.html)。

交付前核对以下成果和边界：

| 检查项 | 应达到的状态 |
|---|---|
| 科学内容 | 结论有证据，理论/观察/解释/计划清楚，缺口可见 |
| 数学 | 定义、维度、单位、前后推导和符号映射一致 |
| 引文 | 文献身份与字段核实，引用键和交叉引用有效 |
| 版面 | 总览与相关全尺寸页面已检查，无遮挡、裁切和不可读内容 |
| 对应关系 | 详细说明、slides、数据和图表来自同一修订版本 |
| 交付 | 源稿、请求格式、原始资源和必要复现脚本保留 |
| 同步 | 只在授权的仓库和分支操作，实际确认提交/推送结果 |

编译成功不能替代科学验证和视觉检查。交付说明应报告实际命令、输出位置、缺失工具和未完成项。Git 采用一个连贯修订一次检查与提交的节奏；分享包不把原作者的自动推送许可转授给接收者。
